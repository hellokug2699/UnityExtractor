# P1.3：资源类型识别与分类

## 目标

在对象枚举阶段，根据 Unity 原生对象类型提供保守、可追溯的资源分类。此阶段只增加元数据，不读取或导出资源 Payload。

## 分类原则

- 只使用精确的 Unity 类型名称进行分类。
- 不根据对象名称、文件名、扩展名或猜测的 Payload 内容推断类型。
- 未收录的类型统一标记为 `unknown`，不阻断对象枚举。
- 保留原始 `type_name`，并同时输出分类依据和置信度。
- 分类字段属于附加信息，不改变现有对象身份、引用关系或依赖图语义。

## 输出字段

每个对象新增：

- `resource_category`：资源大类。
- `resource_subcategory`：资源子类。
- `classification_confidence`：当前仅对明确匹配的 Unity 类型标记为 `high`，未知类型为 `unknown`。
- `classification_basis`：分类依据；当前为 `unity_type_name` 或 `unrecognized_unity_type`。

## 首批分类

| 大类 | Unity 类型示例 |
| --- | --- |
| image | Texture2D、Sprite、Cubemap、SpriteAtlas |
| audio | AudioClip、AudioMixer |
| model | Mesh、MeshFilter、SkinnedMeshRenderer |
| material | Material、Shader |
| animation | AnimationClip、Animator、Avatar |
| scene | GameObject、Transform、RectTransform |
| script | MonoBehaviour、MonoScript |
| data | TextAsset、ScriptableObject |
| font | Font |
| video | VideoClip |
| container | AssetBundle、ResourceManager |
| unknown | 未识别或自定义类型 |

## 验收范围

- 已知类型精确映射到预期分类。
- 未知类型不因名称相似而误分类。
- 对象报告包含分类字段。
- 原有对象枚举、引用分析和依赖图测试保持通过。
- 使用真实 APK 检查分类分布，并抽查代表性对象。

本阶段不承诺识别自定义 MonoBehaviour 的业务语义，也不代表纹理、音频、网格等 Payload 已解码。
